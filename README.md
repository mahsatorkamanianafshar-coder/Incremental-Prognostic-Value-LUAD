# Exploratory Evaluation of the Incremental Prognostic Value of a Transcriptomic Model in Lung Adenocarcinoma

This repository contains the code, analysis workflows, and reproducibility materials associated with the study:

**“Exploratory Evaluation of the Incremental Prognostic Value of a Transcriptomic Model in Lung Adenocarcinoma”**

## Overview

This study evaluates the incremental prognostic value of a transcriptomic model in lung adenocarcinoma (LUAD) beyond available clinical predictors.

The analysis includes leakage-controlled nested cross-validation, Elastic Net Cox modeling, internal validation, and external validation using independent LUAD cohorts.

## Data Sources

The study uses publicly available datasets, including:

- TCGA-LUAD
- GSE72094
- GSE31210

Due to data redistribution restrictions and file-size limitations, raw expression data are not stored directly in this repository. Instructions for accessing the original datasets are provided with the analysis documentation.

## Repository Contents

- `code/` – analysis and modeling scripts
- `results/` – reproducibility outputs and model results
- `figures/` – figures generated from the analyses
- `supplementary/` – supplementary reproducibility materials
- `environment/` – software and package information

## Reproducibility

The repository is intended to provide the materials necessary to reproduce the main analyses reported in the manuscript.
